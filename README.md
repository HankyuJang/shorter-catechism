# 소요리문답 웹앱

웨스트민스터 소요리문답 107문을 휴대폰에서 읽는 앱입니다. 본문은 저장소에 없고, 처음 실행할 때 사용자가 붙여넣은 내용을 그 기기에만 저장합니다.

## GitHub Pages로 배포

1. 새 저장소를 만들고 이 폴더의 파일을 모두 저장소 맨 위에 올립니다.
2. Settings > Pages에서 Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 정하고 저장합니다.
3. 잠시 후 표시되는 `https://아이디.github.io/저장소이름/` 주소를 휴대폰에서 엽니다.

## 휴대폰에 설치

- 아이폰: Safari 공유 버튼 > 홈 화면에 추가. 그다음 추가된 앱을 열어 문답을 붙여넣습니다.
- 안드로이드: Chrome 메뉴 > 홈 화면에 추가 또는 앱 설치.

## 코드를 고친 뒤

`sw.js` 맨 위의 `wsc-v1` 숫자를 올려야 휴대폰에 새 버전이 적용됩니다.
